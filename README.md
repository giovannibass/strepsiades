# Strepsiades

Strepsiades is a chess engine written in Python. The name comes from a character in the ancient Greek comedy *The Clouds by Aristophanes*.

This project currently supports:
- Chessboard representation in terminal
- Loading positions from FEN strings
- Command-line interface
- Knight move generation
- Sliding move generation (rooks, bishops, and queens)
- Pawn move generation.
- King move generation.
- Making and undoing moves
- Board logic for detecting attacked squares and checks
- Added legal move generation
